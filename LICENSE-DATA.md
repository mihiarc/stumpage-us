# Data license — CC BY 4.0

Two generated datasets are published here, both licensed under the
[Creative Commons Attribution 4.0 International license (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/):

- **`public/data/`** — the harmonized price records, series index, aggregates,
  dimension metadata, and candor blocks. Generated upstream by
  `scripts/export_public.py` in the private `mihiarc/timber-prices` repo.
- **`public/coverage/`** — the coverage record: which organizations publish US
  timber prices, how current each report is, whose data it is, and which states
  were searched with no source found, joined against the price series actually
  present in the dataset. Generated by `scripts/export-coverage.ts` in this
  repo from the hand-maintained catalogue in `src/content/directory.ts`.

The coverage record contains no price values — only metadata about who
publishes them — so it carries no licensing exposure from the services it
catalogues.

You are free to share and adapt the dataset for any purpose, including
commercially, provided you give appropriate credit (see `CITATION.cff`),
link to the license, and indicate if changes were made.

Notes on the underlying facts:

- Every record derives exclusively from public sources: US federal
  public-domain works (USFS Cut-and-Sold reports, USFS PNW Research Station
  PPET series), state agency publications (Michigan DNR, Oregon ODF, Montana
  DNRC), and the University of Montana BBER survey. Each row carries its
  source attribution (`source_code`, `source_name`); please also credit the
  original publishing agency when quoting specific prices.
- The CC BY 4.0 license applies to the compilation — the selection,
  harmonization, unit conversions, cataloguing, and documentation. The underlying federal
  works remain public domain.
- Licensed TimberMart-South / TimberMart-North data is **excluded by
  construction** and verified by automated test on every build; nothing in
  this repository derives from those services.

`LICENSE`).
